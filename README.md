# 🎵 Melodify – Music Player

Melodify is a modern, responsive JavaScript music player built as part of the CodeAlpha Frontend Development Internship.

## ✨ Features

- ▶️ Play / Pause music
- ⏮️ Previous song
- ⏭️ Next song
- 🔀 Shuffle mode
- 🔁 Repeat mode
- 📊 Music progress bar
- 🔊 Volume control
- 🔇 Mute / Unmute
- 🎵 Add local music files
- 📋 Playlist management
- 🗑️ Delete songs
- ❤️ Favorite songs
- 🔍 Search songs and artists
- 🌙 Dark / Light theme
- ▶️ Autoplay
- ⌨️ Keyboard controls
- 💾 Songs persist using IndexedDB
- 📱 Fully responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML5 Audio API
- IndexedDB
- Responsive Web Design
